# AulaNova

Piattaforma SaaS per centri di formazione.

## Ambienti

- **Public**: home accessi + piani (`/`, `/piani`)
- **Admin**: configurazione, calendario, studenti, rate, attestati
- **Docente**: corsi, materiali, DAD, valutazioni, messaggi admin
- **Studente**: home mobile-first, corsi, video, download

## Avvio

```bash
npm install
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000).

Accessi demo: `/accesso/admin`, `/accesso/docente`, `/accesso/studente` (oppure entra senza login dalle form).
